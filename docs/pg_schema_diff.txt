=== Beebo SQLite -> PostgreSQL schema comparison ===

Intentional differences (explained):
  - community_members.seq (BIGINT IDENTITY UNIQUE) replaces SQLite rowid ordering; no SQLite counterpart
  - id columns: INTEGER PRIMARY KEY AUTOINCREMENT -> BIGINT GENERATED BY DEFAULT AS IDENTITY
  - FK columns: INTEGER -> BIGINT
  - TIMESTAMP DEFAULT CURRENT_TIMESTAMP -> TIMESTAMPTZ DEFAULT now()
  - communities.created_at / community_members.joined_at: TEXT (datetime('now')) -> TIMESTAMPTZ NOT NULL DEFAULT now()
  - users.username: UNIQUE ... COLLATE NOCASE -> UNIQUE INDEX on lower(username)
  - schema_migrations.applied_at: TIMESTAMP -> timestamptz DEFAULT now()
